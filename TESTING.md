## Размеры

Основные сценарии: 320, 360, 390, 600, 700, 768, 900, 1024, 1280, 1440, 1920 px. Дополнительные границы адаптива: 701 и 901 px. Короткий горизонтальный экран: 844 × 390.

## Функциональность

- Нет горизонтального переполнения страницы.
- Единый размер слов второй строки и общая базовая линия.
- Пять различных контуров капель, одинаковый цвет букв и потёков, отсутствие ненадёжного CSS-фильтра.
- Фактически видимые пиксели надписи при заблокированных WOFF, отключённом JS и открытии index.html напрямую. Эти сценарии проверяют заголовок, не обещают работу корзины без JS.
- Верхние кнопки имеют высоту 44 px.
- Клякса после всех трёх контактов, внутри ширины окна; изображение целое.
- Сравнены координаты начала всех секций с исходным архивом на 390 и 1440 px: совпадают.
- Пустая и заполненная корзина, количество, сумма, удаление, сохранение после обновления.
- Выбор размера футболки и сообщение при отсутствии размера.
- Валидация формы и локальный черновик.
- Категории, поиск, пустая выдача и восстановление выдачи.
- Мобильное меню, Tab, Escape, возврат фокуса и удержание фокуса внутри диалога.
- Нить: движение, затухание, конечные координаты, отсутствие петель, Home/End и reduced motion.

В основных функциональных сценариях: ошибок JavaScript и неудачных запросов нет. В отдельном тесте font-blocked запросы шрифтов намеренно прерываются.

## Визуальная проверка

Просмотрены главный экран на телефоне, планшете и десктопе, компактная навигация, контакты, каталог, мерч, о проекте, FAQ, мобильное меню, пустая/заполненная корзина, ошибки формы, готовый черновик, узкий и горизонтальный экраны. Намеренное перекрытие букв котом на десктопе сохранено по исходной композиции. В футере пятно не перекрывает текст.

## Повторный запуск

Нужны Python, Playwright, Pillow и Chromium. Самому сайту эти инструменты не нужны.

Запустите сервер в корне сайта:

```bash
python3 -m http.server 8765
```

В другом терминале:

```bash
python3 qa/test_corrections.py
python3 qa/test_site.py
python3 qa/test_extra.py
python3 qa/test_v3.py
```

Путь к браузеру можно задать CHROMIUM_EXECUTABLE для исходных наборов. Результаты сохраняются в qa/output и qa/output-v3; QA_OUTPUT позволяет изменить каталог. SITE_URL задаёт адрес сервера.

JSON исходного прогона находятся в `qa/results-v3/`. Сравнение с оригиналом требует исходного присланного zip; он не дублируется в этом архиве.
