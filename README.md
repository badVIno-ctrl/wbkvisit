# WBK Shop
​
**Книги, от которых не уснуть.**
​
Сайт-визитка книжной лавки «Кот Бегемот»: книги, мерч и интерактивный каталог в чёрно-алой хоррор-эстетике.
​
![Главный экран WBK Shop](https://github.com/user-attachments/assets/84edc906-af44-4568-a54f-2e822851f692)
​
## Возможности
​
- Каталог с поиском, категориями и сортировкой.
- Корзина с изменением количества и подсчётом суммы.
- Выбор размера футболки.
- Сохранение корзины в браузере при доступном localStorage.
- Создание и скачивание черновика заказа.
- Адаптивная вёрстка и мобильное меню.
