## О проекте
​
Я сделал сайт-визитку для «Кота Бегемота», чтобы передать атмосферу страшных историй не только текстом, но и самим интерфейсом.
​
За основу взял эстетику хоррор-постера: почти чёрный фон, алую типографику, потёки и монохромную иллюстрацию кота с лампой. Вокруг этой композиции собрал каталог книг и мерча, информацию о проекте и контакты.
​
Хотелось, чтобы сайт выглядел как часть этого мира, но оставался понятным и удобным на телефоне и компьютере.
​
> Оставьте свет включённым.
​
## Возможности
​
| Атмосфера | Интерфейс |
| :--- | :--- |
| Фактурный заголовок с органичными потёками | Каталог с категориями, поиском и сортировкой |
| Чёрно-алая палитра и оригинальные иллюстрации | Карточки товаров и выбор размера одежды |
| Декоративная нить, реагирующая на прокрутку | Демонстрационная корзина с сохранением в браузере |
| Сдержанные анимации и состояния кнопок | Локальный черновик заказа без отправки данных |
​
Также предусмотрены адаптивная вёрстка, мобильное меню, управление с клавиатуры, видимый фокус и уменьшение анимаций при включённом `prefers-reduced-motion`.
​
## Под капотом
​
**HTML, CSS и JavaScript без фреймворков и сборки.**
​
- Изображения, иконки и шрифты хранятся в проекте.
- Главное начертание собрано из SVG-контуров: надпись не исчезает, если шрифт не загрузился.
- Корзина работает на стороне браузера и использует `localStorage`.
- Для сайта не нужны npm, база данных или серверная часть.
​
## Локальный запуск
​
Скачайте репозиторий, распакуйте его и откройте `index.html`. Не отделяйте его от остальных файлов проекта.
​
Либо запустите простой локальный сервер из корня проекта:
​
```bash
python3 -m http.server 8765
```
​
Затем откройте **http://localhost:8765**.
​
## Публикация на GitHub Pages
​
Проект технически готов к статической публикации: дополнительных команд сборки нет.
​
1. Создайте репозиторий на GitHub, например `wbk-shop`.
2. Загрузите **содержимое папки проекта в корень репозитория**. Файл `index.html` должен лежать рядом с `README.md`, а не во вложенной папке.
3. Откройте **Settings → Pages**.
4. В **Build and deployment → Source** выберите **Deploy from a branch**.
5. Укажите ветку **main** и папку **/(root)**, затем нажмите **Save**.
6. Дождитесь завершения публикации. GitHub покажет адрес сайта в разделе Pages.
​
Обычный адрес сайта проекта:
​
```text
https://<github-username>.github.io/wbk-shop/
```
​
Файл `.nojekyll` уже включён. Он отключает обработку проекта Jekyll. Пути к ресурсам относительные, поэтому сайт может открываться из подпапки репозитория.
​
> **Важно:** GitHub Pages подходит здесь для демонстрации интерфейса и портфолио, но не для работы настоящего интернет-магазина. GitHub запрещает использовать Pages как бесплатный хостинг для электронной торговли. Перед публикацией неофициальной учебной версии нужно явно обозначить её статус непосредственно на сайте и проверить права на материалы.
​
[Настройка публикации](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site) · [Ограничения GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/github-pages-limits)

## Проверка
​
В локальной среде пройдено **285 функциональных и регрессионных проверок в Chromium**: адаптивность, каталог, корзина, форма, меню и клавиатурная навигация. Проверены ширины от 320 до 1920 px и устойчивость главного заголовка к отключённой загрузке шрифтов.

Safari/iOS и Firefox не проверялись. Подробности и команды повторного запуска — в [TESTING.md](TESTING.md).
