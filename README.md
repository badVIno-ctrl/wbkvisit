# WBK Shop · v3

Исправленная локальная версия сайта из присланного архива. Исходная чёрно-алая композиция, кот, книги и товарные фотографии сохранены.

## Запуск

Распакуйте **весь архив** и откройте `index.html`. Папка `assets`, оба CSS и оба JavaScript должны оставаться рядом. Сборка и npm не нужны.

Альтернатива для проверки через HTTP:

```bash
python3 -m http.server 8765
```

Откройте `http://localhost:8765`.

## Исправления

1. Главная надпись: исходное кириллическое начертание Cormorant переведено в SVG-контуры с фактурой. Нет внешнего SVG-фильтра на HTML-тексте, который мог делать надпись невидимой. Главный заголовок виден даже при блокировке файлов шрифтов или отключённом JavaScript. Доступное название H1 сохранено.
2. Капли: пять разных криволинейных силуэтов, разные длина и толщина. Буквы и капли используют один цвет `--poster-red`, связанный с `--blood: #cf2632`. Внутренние пиксели фактуры непрозрачны; сглаживание остаётся только на границах. Цвет клякс также нормализован, без затемняющей прозрачности.
3. Верхние кнопки: высота 44 px вместо 48, текст 18 px вместо 23/22, уменьшенные горизонтальные отступы, иконка и счётчик. Клавиатурный фокус и удобная зона нажатия сохранены.
4. Контакты: клякса шириной до 240 px стоит непосредственно под email, телефоном и ссылкой ВКонтакте. Изображение находится в обычном потоке внутри контактной колонки. Нет отрицательных отступов, абсолютного позиционирования или перекрытия текста. Координаты начала всех верхних секций совпадают с исходным архивом на 390 и 1440 px.

## Состав

- `index.html` — разметка и векторное оформление заголовка.
- `styles.css` — исходные компоненты; удалены устаревшие ссылки на фильтр.
- `refinements.css` — точечные исправления постера, навигации и контактов.
- `app.js`, `effects.js` — каталог, демонстрационная корзина, форма и нить прокрутки.
- `assets/` — локальные иллюстрации, шрифты, товары, favicon.
- `previews/` — актуальные снимки главного экрана и контактов.
- `WORKLOG.md` — мини-планы по каждой детали и интернет-источники.
- `TESTING.md`, `qa/` — методика и результаты тестов.
- `licenses/` — лицензии, поставлявшиеся с исходным проектом.

## Проверка и ограничения

285 функциональных и регрессионных проверок прошли в headless Chromium. Проверены 13 ширин от 320 до 1920 px, горизонтальный экран 844 × 390, отключённые шрифты, отключённый JavaScript для главного заголовка и открытие через `file://`. Контраст: 12 из 12 измеренных пар прошли проверку.

Это лабораторные тесты Chromium, не испытание на физических телефонах. Safari/iOS и Firefox в этой среде не доступны и не проверялись. Полный отчёт — в `TESTING.md`.

Сайт по-прежнему демонстрационный: заказы не отправляются, платежи не подключены. Корзина хранится в текущем браузере; форма не отправляет персональные данные на сервер. Цены, наличие и права на исходные изображения не перепроверялись. На действующий домен файлы не загружались.
