# WBK Shop
​
**Книги, от которых не уснуть.**
​
Сайт-визитка книжной лавки «Кот Бегемот»: книги, мерч и интерактивный каталог в чёрно-алой хоррор-эстетике.
​
![Главный экран WBK Shop](https://github.com/user-attachments/assets/84edc906-af44-4568-a54f-2e822851f692)
​
## Возможности
​
- Каталог с поиском, категориями и сортировкой.
- Корзина с изменением количества и подсчётом суммы.
- Выбор размера футболки.
- Сохранение корзины в браузере при доступном localStorage.
- Создание и скачивание черновика заказа.
- Адаптивная вёрстка и мобильное меню.
​
## Технологии
​
HTML, CSS и JavaScript. Без фреймворков, npm и сборки. Изображения и шрифты хранятся в папке `assets`.
​
## Локальный запуск
​
Скачайте проект целиком и откройте `index.html` в браузере.
​
Для запуска через локальный сервер выполните в папке проекта:
​
```bash
python3 -m http.server 8765
```
​
Затем откройте http://localhost:8765.
​
## Публикация на GitHub Pages
​
1. Загрузите в корень репозитория содержимое папки `WBK-Shop-v3`, включая папку `assets`. Файл `index.html` должен быть в корне, а не во вложенной папке.
2. Откройте **Settings → Pages**.
3. В разделе **Build and deployment** выберите **Source → Deploy from a branch**.
4. Выберите ветку **main** и папку **/ (root)**, затем нажмите **Save**.
5. Дождитесь завершения публикации. Адрес сайта появится в разделе **Pages**.
​
## Файлы проекта
​
```text
index.html        — страница сайта
styles.css        — основные стили
refinements.css   — дополнительные стили
app.js            — каталог, корзина и форма
effects.js        — визуальные эффекты
assets/           — изображения, шрифты и иконки
previews/         — скриншоты сайта
qa/               — тесты и сохранённые результаты
licenses/         — лицензии сторонних материалов
```

## Важно
​
Это демонстрационный проект: заказы не отправляются, оплата не подключена. Форма создаёт только локальный черновик. Цены, наличие и доставку необходимо уточнять у магазина.
